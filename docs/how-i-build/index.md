# How I Build

I'm experimenting with structured agent-assisted software development: planning, implementation, independent review, repair, and testing, with explicit human control boundaries.

**Agents may build and review. I own the final merge.**

The process is evolving. Modeling objects and relationships before generating navigation is one part of that work; validation gates and review loops are another.

[Field Notes](../notes/index.md) will document lessons from these experiments.
